# Full-Bleed Backgrounds and Grouped Table Headers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the page-specific background images fill the main content region and restore the legacy data table's semantic multi-column header grouping.

**Architecture:** Keep the shared shell's 24px main padding unchanged for all routes. Make the page-background wrapper offset that padding with a negative margin and matching internal padding. Replace only the data table's flat column definition with nested TanStack column groups so the existing table component generates a grouped two-row header.

**Tech Stack:** Next.js 16, React 19, TypeScript, SCSS modules, `@bayareametro/mtc-ui` DataTable, TanStack Table column definitions, Playwright.

## Global Constraints

- Preserve the shared shell, navigation, content, data fetching, and table values.
- Change only the page-background wrapper styling needed to offset the shell's main padding.
- Change the data table column definition to use nested header groups.
- Keep the existing light translucent background veil and responsive cover behavior.
- Do not change unrelated routes or global layout spacing.
- Preserve semantic table headers generated by the existing table component.
- Use column groups only for visual and structural grouping; do not alter data labels or values.
- Verify that desktop grouped headers align with their leaf columns.
- Verify that mobile pages do not introduce horizontal overflow beyond the table's existing behavior.
