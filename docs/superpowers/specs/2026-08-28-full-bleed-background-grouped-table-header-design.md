# Full-Bleed Backgrounds and Grouped Table Headers

## Goal

Make the page-specific background images fill the usable main-content region while preserving the shared shell spacing, and format the data table with semantic multi-column header groups matching the legacy presentation.

## Scope

- Preserve the shared shell, navigation, content, data fetching, and table values.
- Change only the page-background wrapper styling needed to offset the shell's main padding.
- Change the data table column definition to use nested header groups.
- Keep the existing light translucent background veil and responsive cover behavior.
- Do not change unrelated routes or global layout spacing.

## Design

The page background wrapper will extend through the shared main area's 24px padding with a negative margin, then restore equivalent internal padding for its children. This keeps the background image full-bleed within the main content area without changing the shell's spacing for other pages.

The data table will use TanStack Table's nested column definitions. The top header row will contain `Population Segment`, `Persons`, `Non-commercial Passenger Vehicle Miles Traveled`, and `Vehicle miles traveled per capita`. The VMT group will span the existing value and percentage columns for entirely within, partially in, and entirely outside travel. Leaf columns will retain their current accessors and cell formatting.

## Accessibility and Responsive Behavior

- Preserve semantic table headers generated by the existing table component.
- Use column groups only for visual and structural grouping; do not alter data labels or values.
- Keep the background veil so foreground content maintains readable contrast.
- Verify that desktop grouped headers align with their leaf columns.
- Verify that mobile pages do not introduce horizontal overflow beyond the table's existing behavior.

## Verification

- Run the web production build.
- Run the web test suite and record any environment-sensitive failures.
- Inspect home and data routes at desktop and mobile widths.
- Confirm the home and data background URLs are present and the backgrounds reach the main content edges.
- Confirm the grouped table header exposes the expected group and leaf labels.
